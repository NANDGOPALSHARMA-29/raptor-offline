# RAPTOR Offline 🦖

**Decentralized Offline Mesh Messaging System**

RAPTOR Offline is a peer-to-peer messaging application that enables nearby devices to communicate without internet connectivity or centralized servers.

### Architecture

```text
Android App (Kotlin)
       |
       v
Device Discovery & Connection
       |
       v
Mesh Networking Engine
(Routing, TTL, Message Forwarding)
       |
       v
Bluetooth / Wi-Fi
       |
       v
Nearby Devices (Mesh Network)
       |
       v
Local Storage (Room / SQLite)
```

### Tech Stack
- Kotlin
- Jetpack Compose
- Google Nearby Connections
- Bluetooth / Wi-Fi
- Room Database
